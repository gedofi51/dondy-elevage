# ALERTES

Créer un moteur d'alertes pour :

* mortalité anormale ;
* stock faible ;
* alimentation insuffisante ;
* médicament proche de péremption ;
* vaccination à réaliser ;
* tâche en retard ;
* vente prévue ;
* anomalie de poids ;
* incident sanitaire ;
* maintenance ;
* impayés.

Prévoir les niveaux :

* INFO
* VIGILANCE
* IMPORTANT
* CRITIQUE
