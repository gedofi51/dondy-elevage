# FINANCES

Enregistrer :

* recettes ;
* dépenses ;
* catégories ;
* paiements ;
* charges ;
* investissements.

Calculer :

* chiffre d'affaires ;
* dépenses ;
* marge ;
* résultat ;
* coût par poulet ;
* coût par œuf ;
* rentabilité par bande ;
* rentabilité par période.

Ne jamais mélanger données financières estimées et données comptables réelles.
