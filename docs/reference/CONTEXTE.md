# CONTEXTE

DONDY ELEVAGE est une ferme avicole située à **Samba, en République centrafricaine**.

L'application doit permettre de centraliser et automatiser la gestion de l'exploitation, notamment :

* poulets de chair ;
* poules pondeuses ;
* bandes d'élevage ;
* poussins ;
* mortalité ;
* alimentation ;
* eau ;
* poids et croissance ;
* vaccination ;
* traitements ;
* biosécurité ;
* production d'œufs ;
* stocks ;
* achats ;
* fournisseurs ;
* ventes ;
* clients ;
* dépenses ;
* recettes ;
* trésorerie ;
* personnel ;
* maintenance ;
* bâtiments ;
* alertes ;
* tâches ;
* rapports ;
* tableaux de bord.

L'application doit être pensée comme un **SaaS moderne, responsive et évolutif**, utilisable sur ordinateur, tablette et smartphone.

Elle devra fonctionner correctement dans un environnement où la connexion Internet peut être lente ou instable.
