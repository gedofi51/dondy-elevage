# DOCKER ET DÉPLOIEMENT

Créer des environnements distincts :

* développement ;
* test/staging ;
* production.

Docker Compose peut orchestrer :

* Front-end ;
* API ;
* MySQL ;
* Nginx.

Ne jamais utiliser les identifiants de production dans le dépôt Git.

Prévoir volumes persistants, sauvegardes et redémarrage automatique des services.
