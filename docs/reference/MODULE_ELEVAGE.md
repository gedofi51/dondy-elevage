# MODULE ÉLEVAGE

Chaque bande doit contenir notamment :

* identifiant ;
* référence ;
* type de production ;
* souche ;
* fournisseur ;
* bâtiment ;
* date d'arrivée ;
* effectif initial ;
* effectif actuel ;
* âge ;
* statut ;
* date prévisionnelle de vente ;
* observations.

Suivre quotidiennement :

* mortalité ;
* poids ;
* consommation d'aliment ;
* consommation d'eau ;
* température si disponible ;
* traitements ;
* vaccins ;
* incidents.

Calculer automatiquement :

**Mortalité (%) = morts cumulés / effectif initial × 100**

**GMQ = variation de poids / nombre de jours**

**Indice de consommation = aliment consommé / gain de poids**

Pour les poulets de chair, prévoir un suivi complet de **J1 à J45**, avec alertes et étapes clés.
