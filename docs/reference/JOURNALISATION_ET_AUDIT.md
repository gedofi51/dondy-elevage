# JOURNALISATION ET AUDIT

Journaliser les opérations sensibles :

* connexion ;
* création/suppression utilisateur ;
* changement de rôle ;
* modification financière ;
* vente ;
* stock ;
* mortalité ;
* traitement sanitaire ;
* paramètres.

Conserver :

* utilisateur ;
* action ;
* ressource ;
* date ;
* adresse IP si pertinente ;
* ancienne/nouvelle valeur lorsque nécessaire.
