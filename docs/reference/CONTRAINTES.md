# CONTRAINTES

Toujours privilégier :

* simplicité ;
* maintenabilité ;
* sécurité ;
* performance ;
* ergonomie ;
* faible consommation réseau ;
* évolutivité ;
* traçabilité.

Ne pas :

* surarchitecturer ;
* ajouter des dépendances sans justification ;
* dupliquer du code ;
* exposer des secrets ;
* contourner TypeScript ;
* placer la logique métier critique uniquement côté client ;
* supprimer des données sensibles sans traçabilité ;
* casser une fonctionnalité existante pour en développer une nouvelle.

La priorité est de produire une **V1 solide et exploitable**, puis d'ajouter progressivement les fonctionnalités avancées.

**Finalité : construire DONDY ELEVAGE comme un véritable système d'information avicole SaaS, capable de piloter l'exploitation depuis Samba ou à distance, avec des données fiables, des alertes pertinentes et une vision claire de la rentabilité.**
