# TABLEAU DE BORD

Afficher notamment :

* effectif total ;
* bandes actives ;
* mortalité du jour ;
* mortalité cumulée ;
* poids moyen ;
* consommation ;
* stocks critiques ;
* œufs produits ;
* ventes ;
* dépenses ;
* marge ;
* alertes ;
* tâches du jour.

Prévoir des graphiques simples, lisibles et adaptés au mobile.

# UX/UI

L'application doit être :

* responsive ;
* Mobile First ;
* claire ;
* rapide ;
* intuitive ;
* utilisable par du personnel non technique.

Utiliser Shadcn UI pour assurer la cohérence des composants.

Éviter les écrans surchargés.

Les formulaires importants doivent :

* utiliser React Hook Form ;
* être validés avec Zod ;
* afficher clairement les erreurs ;
* protéger contre les doubles soumissions ;
* confirmer les actions destructives.
