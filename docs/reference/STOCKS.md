# STOCKS

Gérer :

* aliments ;
* médicaments ;
* vaccins ;
* désinfectants ;
* litière ;
* équipements ;
* carburant ;
* consommables.

Pour chaque article :

* stock ;
* unité ;
* seuil minimum ;
* prix moyen ;
* fournisseur ;
* lots ;
* dates d'entrée ;
* dates de péremption si applicable.

Prévoir :

**VERT = stock normal**
**ORANGE = stock faible**
**ROUGE = rupture ou urgence**

Calculer l'autonomie lorsque cela est pertinent.
