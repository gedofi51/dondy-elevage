## Qualité attendue
Le code doit être :
lisible
fortement typé
documenté
modulaire
réutilisable
sécurisé
performant
évolutif
Aucune fonctionnalité ne doit être simulée. Toutes les fonctionnalités doivent être implémentées de manière opérationnelle.
Avant chaque développement, proposer l'architecture de la base de données, les diagrammes UML, les diagrammes de séquence et l'arborescence complète du projet.
Le développement doit être découpé en modules indépendants afin de faciliter les évolutions futures.
Chaque étape doit être validée avant de passer à la suivante.
Dispose d'un menu contextuel.
