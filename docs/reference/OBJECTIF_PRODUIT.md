# OBJECTIF PRODUIT

Construire une plateforme permettant au responsable de DONDY ELEVAGE de :

**Enregistrer → Suivre → Mesurer → Alerter → Analyser → Décider → Planifier → Contrôler.**

L'application doit réduire la gestion papier et fournir une vision claire de :

* l'état du cheptel ;
* la mortalité ;
* les performances des bandes ;
* les stocks ;
* les coûts ;
* la production ;
* les ventes ;
* la rentabilité ;
* les anomalies ;
* les actions à réaliser.
