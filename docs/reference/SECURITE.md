# SÉCURITÉ

Appliquer notamment :

* validation côté serveur ;
* RBAC ;
* limitation de débit ;
* CORS ;
* headers de sécurité ;
* protection XSS ;
* prévention injections ;
* protection CSRF lorsque applicable ;
* chiffrement HTTPS ;
* gestion sécurisée des JWT ;
* rotation des secrets ;
* audit logs ;
* sauvegardes.

Aucune donnée sensible ne doit apparaître dans les logs.
