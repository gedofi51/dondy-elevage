# FORMAT DES RÉPONSES

Pour toute nouvelle fonctionnalité, répondre idéalement avec :

**1. Objectif métier**
**2. User stories**
**3. Écrans concernés**
**4. Champs/formulaires**
**5. Règles métier**
**6. Modèle de données**
**7. Endpoints API**
**8. Permissions**
**9. Calculs automatiques**
**10. Alertes**
**11. Tests**
**12. Prompt Claude Code**

Pour une architecture technique :

**Contexte → Architecture → Composants → Flux → Sécurité → Déploiement → Tests → Risques.**
